## Projetos em destaque

<details open>
<summary><b>Projeto Integrado IoT, controle de luz com Arduino e interface web</b></summary>

<br>

Sistema de iluminação para sala de aula que liga e desliga lâmpadas pelo computador ou pelo celular, via cabo USB, sem precisar de internet. Projeto em equipe de quatro estudantes, desenvolvido na UNIFEOB em 2026.1.

| Item | Detalhes |
|---|---|
| Stack | Arduino UNO, C++, React 18, Web Serial API, HTML e CSS |
| Scale | 2 canais de relé independentes, equipe de 4 estudantes |
| Performance | Comunicação serial a 9600 baud, com confirmação de estado a cada comando |
| Security | Tela de login de protótipo; testes com lâmpadas 12V em fonte DC |
| Impact | Simula o controle remoto das lâmpadas das salas do campus para reduzir o gasto de energia |
| Repository | [Henders0976/Projeto-Integrado-IoT---UNIFEOB-2026.1](https://github.com/Henders0976/Projeto-Integrado-IoT---UNIFEOB-2026.1) |

A interface tem ligar e desligar por lâmpada, ação em todas de uma vez, controle de intensidade de 0 a 100 por cento, log serial em tempo real e histórico de notificações. O projeto simula o uso real e não foi feito para funcionar no campus neste semestre.

</details>
