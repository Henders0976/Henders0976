<summary><b>RV Label, app Flutter para uma loja de roupas femininas</b></summary>

<br>

Projeto integrado de 2026.2. Estou transformando o site de uma loja de roupas femininas em um app Flutter orientado a objetos, com catálogo em MySQL, API em Node.js e pedido fechado pelo WhatsApp.

| Item | Detalhes |
|---|---|
| Stack | Flutter, Dart, Node.js, MySQL, Firebase AI Logic |
| Escopo | App, API e banco de dados em um único fluxo de pedido |
| Impacto | Leva o catálogo da loja para um app e simplifica o fechamento do pedido pelo WhatsApp |

<summary><b>Projeto Integrado IoT, controle de luz com Arduino e interface web</b></summary>

<br>

Sistema de iluminação para sala de aula que liga e desliga lâmpadas pelo computador ou pelo celular, via cabo USB, sem precisar de internet. Projeto em equipe de quatro estudantes, desenvolvido na UNIFEOB em 2026.1.

| Item | Detalhes |
|---|---|
| Stack | Arduino UNO, C++, React 18, Web Serial API, HTML e CSS |
| Escopo | 2 canais de relé independentes, equipe de 4 estudantes |
| Desempenho | Comunicação serial a 9600 baud, com confirmação de estado a cada comando |
| Repositório | [Henders0976/Projeto-Integrado-IoT---UNIFEOB-2026.1](https://github.com/Henders0976/Projeto-Integrado-IoT---UNIFEOB-2026.1) |
