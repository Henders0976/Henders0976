## Sobre mim

Curso Análise e Desenvolvimento de Sistemas no período noturno da UNIFEOB, em São João da Boa Vista. Nos projetos da faculdade eu gosto de ligar as pontas: modelar o domínio, desenhar o banco, escrever a API e montar a interface que a pessoa usa.

## Em andamento

**RV Label** é o projeto integrado de 2026.2. Estou transformando o site de uma loja de roupas femininas em um app Flutter orientado a objetos, com catálogo em MySQL, API em Node.js e pedido fechado pelo WhatsApp. O repositório é privado por enquanto.
